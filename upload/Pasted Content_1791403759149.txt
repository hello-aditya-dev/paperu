# 9. CRITICAL LIVE BUG: BASENAME INSTEAD OF NATIVE PATH

Several existing workflows still use browser file inputs and later pass:

```ts
file.name
```

to native finalization.

That is WRONG.

Rust expects a canonical absolute path such as:

```text
C:\Users\Aditya\Documents\assignment.pdf
```

not:

```text
assignment.pdf
```

At the latest audit, this issue was visible in areas including:

- Portal Ready;
- Print Studio;
- Batch Studio.

Audit everything.

Correct architecture:

```text
Tauri picker / native drop
→ absolute FilePath
→ WorkingFile
→ read_file_bytes
→ processing engine
→ validate
→ finalizeOutput(real absolute sourcePath)
→ structured result
```

No browser basename pretending to be a native path.
